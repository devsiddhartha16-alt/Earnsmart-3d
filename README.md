# 🌍 Earnsmart-3d

AI-powered online learning platform — built for Bangladesh 🇧🇩

## ✨ Features
- 📊 Dashboard with progress stats
- 📚 Course list (AI, Web, Graphics, Freelancing)
- 🎬 Video player + AI notes
- 🤖 AI chat tutor
- 🌍 3D model viewer (Earth, Human body, etc.)
- 🧪 Practice lab with quizzes
- 📱 Installable as Android app (PWA)

## 🚀 Live Site
https://YOUR_USERNAME.github.io/earnsmart-3d/

## 🛠 Tech Stack
React · Vite · Tailwind CSS · React Three Fiber · React Router

## 📲 Install on Android
1. Open the live link in Chrome
2. Tap ⋮ → "Add to Home screen"
3. Done — runs like a native app
